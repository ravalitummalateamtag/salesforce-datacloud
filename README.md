# Salesforce Data Cloud DX Project

Salesforce metadata and Data Cloud deployments via Gearset.

This repository contains a Salesforce DX project structure. Salesforce metadata lives under `force-app/main/default/`, and `manifest/package.xml` is available for manifest-based retrieve and deploy workflows.

Data Cloud source directories are included as empty placeholders. Add only metadata required for the target org and use case; no data sources, mappings, data streams, identity resolution rules, or activation targets are preconfigured.
